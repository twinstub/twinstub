# TwinStub example project

Generated by `twinstub init`. It contains a stateless endpoint and one
stateful scenario with a webhook chain.

## 1. Start a webhook receiver

Any HTTP server that prints requests works. For example:

```sh
python3 -c '
import http.server
class H(http.server.BaseHTTPRequestHandler):
    def do_POST(self):
        n = int(self.headers.get("Content-Length", 0))
        print(self.headers.get("X-TwinStub-Event"), self.rfile.read(n).decode())
        self.send_response(200); self.end_headers()
http.server.HTTPServer(("", 9999), H).serve_forever()
'
```

## 2. Start TwinStub

```sh
twinstub serve
```

## 3. Try the stateless endpoint

```sh
curl -s 'localhost:8080/v1/rates?currency=USD'
# {"currency": "USD", "rate": 1.0, "ts": "..."}

curl -s 'localhost:8080/v1/rates?currency=GBP'
# {"error": "unsupported_currency"}
```

## 4. Run the chargeback scenario

```sh
curl -s -X POST localhost:8080/v1/payments \
  -H 'X-TwinStub-Scenario: payment.chargeback' \
  -H 'Content-Type: application/json' \
  -d '{"order_id": "ord_42", "amount": 1999}'
# {"id": "pay_...", "order_id": "ord_42", "status": "processing"}
```

Watch the receiver: after ~3s a signed `payment.succeeded` webhook arrives,
after ~10 more seconds `payment.chargeback` follows. Poll the state between
the webhooks; the same `order_id` keeps you in the same session:

```sh
curl -s localhost:8080/v1/payments/pay_x -H 'Content-Type: application/json' \
  -d '{"order_id": "ord_42"}' -X GET
```

Note: this scenario keys sessions by `body:$.order_id`, so state polls in
this demo carry the key in the body. Real configs often use `path:{id}` or
`header:X-Idempotency-Key` selectors instead.

## 5. Inspect via the admin API

```sh
curl -s localhost:9090/api/v1/sessions
curl -s localhost:9090/api/v1/deliveries
curl -s -X POST localhost:9090/api/v1/deliveries/<delivery_id>/replay
```

## Files

- `twinstub.yaml` - root config: server ports, webhook targets, includes
- `endpoints/rates.yaml` - stateless endpoints
- `scenarios/payment_chargeback.yaml` - stateful scenario with webhooks
